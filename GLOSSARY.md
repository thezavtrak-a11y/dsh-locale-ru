# Глоссарий ru — DSH Web UI

Контракт терминологии для всех словарей пакета `dsh-locale-ru`.
Перевод должен быть **кнопочным и коротким**: интерфейс плотный, строки попадают
в пилюли, кнопки, заголовки строк настроек и подсказки.

## Стиль

- Никаких «Вы»: интерфейс безличный или на «ты»-нейтральных формулировках
  («Выберите», «Введите» — допустимо, но предпочтительнее «Выбрать», «Ввести»
  в кнопках).
- Кнопки: инфинитив или существительное — «Сохранить», «Отмена», «Копировать».
- Заголовки строк настроек: существительное — «Язык», «Тема», «Модель».
- Многоточие — символ `…`, не три точки.
- Кавычки внутри строк — «ёлочки», если строка сама в JSON в двойных кавычках.
- Не переводить: имена команд (`/model`, `/plan`, `/compact`), идентификаторы,
  названия файлов, `diff`, `JSON`, `PDF`, `URL`, `id`, `API`, `stdout`.
- Плейсхолдеры `{name}`, `{count}`, `{total}`, `{message}` — сохранять ровно как
  есть, включая регистр; порядок слов можно менять.
- Числа/счётчики: «{count} файлов» — согласование по возможности нейтральное
  («файлов: {count}» там, где форма мешает).
